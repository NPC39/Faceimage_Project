# Face Recognition Experiments & Notebooks

This directory is reserved for exploratory AI research, Python scripts, model benchmarking, and threshold testing for face detection and recognition.

## Planned Experiments (Phase 2+)

1. **Face Detection Accuracy & Speed Benchmark**
   - Model comparison: RetinaFace vs. SCRFD
   - Target execution time < 100ms per photo.

2. **Similarity Threshold Calibration**
   - Cosine distance vs. Euclidean distance comparison for InsightFace embeddings (e.g. Buffalo_l / ArcFace).
   - Precision/Recall curve evaluation on sample event photo sets.

3. **Batch Processing Optimization**
   - Parallel face extraction pipeline performance tests.
